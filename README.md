# SquamSandbox

This repository contains a simple Pygame project illustrating a World War II resupply scenario.

## Running the game

1. Create a virtual environment (optional but recommended):
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```
2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch the game:
   ```bash
   python resupply_game/main.py
   ```

If you encounter `ModuleNotFoundError: No module named 'pygame'`, ensure that the
`pip install` command completed successfully and that you are using the correct
Python interpreter.
